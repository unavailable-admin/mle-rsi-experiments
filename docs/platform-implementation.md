## 恢复语义

BatchPlan 保存命名空间、批次身份、策略源码指纹、view hash、父节点、attempt IDs、策略前后 JSON state 和决策原因。已提交历史通过计划恢复显式 state，不再次调用 decide；未提交批次复用相同父节点和已完成 attempts。策略接口以显式 `next_state` 为持久状态，未承诺保存策略进程的任意 Python 隐藏全局变量。

节点、树、批次收据和计划完成状态使用一个 SQLite 事务。重复提交核验整批内容，派生可读索引可重建。模型费用、执行和评分账本属于 MLE，两个存储之间不声称有原子事务。

未知远端请求、仍在运行的残留容器、缺失终态测量的进程可能明确阻塞。恢复会复用已知响应/费用、容器结果、评分结果；不会把未知状态标成成功、自动清账或自动重发。旧格式批次没有计划时拒绝隐式迁移。

## 验证限制

本次未运行重型训练、全量 MLE-bench 或真实付费生成；未重做完整浏览器页面，也未证明 max 档位或算法优化提升奖牌率。容器 fixture 的 API 费用为模拟账单数值，真实 GPU 消耗为零。官方 grader 包装来自现有实现，本次不使用真实 private 数据重新评分。

最终测试汇总、Dream-RSI 提交及文件/行数统计写入 `verification/platform-verification.json`。冻结快照与原工作区检查仅报告源码一致性，不代表正在运行的实验健康检查。
